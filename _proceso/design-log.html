Auditoría del sistema actual

Completado

25 junio 2026

Se importó el index.html a Figma con el plugin HTML to Figma, obteniendo frames con nombres y estructura de auto layout heredada del código.

Se ejecutó Design Lint sobre el frame completo: 438 errores. El número no requiere análisis adicional — es evidencia directa de que el sistema carece de consistencia de tokens, estilos y componentes.

Insight crítico: el diseño debe partir desde lógica Figma, no al revés. No se limpia el código existente — se diseña desde cero en Figma y se traduce.
